LedgerFlow est l'application comptable officielle d'une fondation belge gérant des projets de développement international financés par l'UE. Elle remplace WinBooks.

**Why:** Application autonome Rails 8, distincte de BudgetFlow, communication via API REST JWT.

**How to apply:** Toujours se référer à docs/dev/LedgerFlow_ConceptNote_v2.md comme spécification prescriptive. Toutes les décisions d'architecture sont non-négociables. Implémentation par phases TDD (16 phases). Phase actuelle : Phase 0 — Bootstrap.
