title: A stored document no longer matches its checksum

---
## Symptom
A stored document whose file changed since upload or is gone.
## Frequent causes
1. The file was replaced or damaged on the storage.
2. A restore from a backup lost the file.
## Checks
- `search_documents` (the name): the document and its status.
- `get_audit_trail` (the document): when it was last touched.
## Interpretation
A mismatch with no audit event means the file changed outside the application. A missing file after a restore means the backup was incomplete.
## Fix
1. Upload the original document again and link it to its entry. [[screen:documents]]
## Prevention
Back up the document storage with the database.
## Escalate
Always: a document supporting the books that cannot be proven is a legal matter.
