## Symptom
Two live invoices with the same partner, the same supplier reference, date and total.
## Frequent causes
1. The same paper or PDF invoice entered twice.
2. The same invoice received by e-mail and by the e-invoicing network.
3. A real repeat (a recurring charge with the same reference).
## Checks
- `search_documents` (the partner, the date): are there two documents, or one document used twice?
- `get_journal_entry` (the entries of both invoices): are both posted?
- `get_audit_trail` (both invoices): how each one arrived.
## Interpretation
Two posted entries for one document is a duplicate. Two different documents with the same reference is a supplier error or a legitimate repeat.
## Fix
1. Open both invoices and compare them with the documents received. [[screen:purchases]]
2. Cancel the duplicate by reversing its entry. [[screen:journal]]
3. If both are legitimate, acknowledge the anomaly with the reason. [[screen:consistency]]
## Prevention
Keep the duplicate check on the document import; the same file is refused. [[screen:documents]]
## Escalate
When the duplicate is already paid or declared in a VAT return.
