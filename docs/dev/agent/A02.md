## Le contrat
- **Entrée** : schéma JSON strict (`additionalProperties: false`), validé deux fois (celui envoyé au modèle, puis `Agent::ArgumentValidator` à l'exécution). `company_id`, `entity_id`, `user_id` ne sont dans aucun schéma et sont refusés. Dates ISO 8601, exercice par son numéro d'année (pas d'identifiant), tiers par l'identifiant d'une référence.
- **Sortie** (`Agent::ToolResult`) : `data`, `totals`, `currency`, `as_of`, `filters_applied` (ce qui a vraiment été appliqué, dont « validated only »), `row_count`, `truncated`, `warnings`, `next_cursor`. Montants en chaînes à deux décimales ; un `Float` est refusé. Plafond de 20 Ko : les lignes en trop sont retirées, `truncated` passe à vrai et l'avertissement dit comment affiner.
- **Références** (`Agent::Refs`) : `ref` sur chaque valeur citable ; chacune ouvre un écran réel avec ses filtres (table testée). Une référence inconnue n'ouvre rien.
- **Pagination** : `limit` borné par outil et `cursor` opaque (`Agent::Cursor`) ; un curseur inventé est refusé.
- **Erreurs** : `forbidden` (sans dire si l'objet existe), `not_found`, `invalid_arguments`, `timeout` (10 s), `too_large`, `internal_error` ; jamais de détail interne.
- **Classes de données** : chaque outil déclare la classe de chaque champ (`classify`), pour le masqueur d'A04.
- **Journalisation** : chaque appel est gardé dans `agent_tool_calls` (arguments chiffrés, résultat non conservé) et écrit dans la piste d'audit (R18) sans les arguments.

## Aucun chemin d'écriture
1. **À l'exécution** : le registre lance chaque outil dans un savepoint en `transaction_read_only`, toujours annulé. Une écriture est refusée par PostgreSQL, quoi que fasse le code (`tool_registry_spec`).
2. **Dans le code** : `tool_catalog_spec` lit la source de chaque outil : aucun appel d'écriture, aucun service hors d'une liste de lecture (rapports et modèles lus). Ajouter `Accounting::PostJournalEntry` à un outil fait échouer la suite ; la vérification est elle-même testée sur des sources fabriquées.
3. **Pour chaque outil** : l'exemple partagé « an agent tool » compte les lignes des tables comptables avant et après l'appel.

## Critères d'acceptation (§5)
| # | Critère | Couvert par |
|---|---|---|
| 1 | Aucun outil ne peut écrire | `tool_catalog_spec`, `tool_registry_spec`, exemple partagé |
| 2 | Arguments hors schéma, hors limites ou d'une autre société refusés | `argument_validator_spec`, exemple partagé (`company_id`), specs d'isolation par outil |
| 3 | Montants en chaînes à deux décimales | `tool_result_spec`, exemple partagé (aucun `Float`) |
| 4 | Parité avec le rapport pour les mêmes filtres | `report_tools_spec`, `other_tools_spec` |
| 5 | Troncature au-delà de la taille maximale | `tool_result_spec` |
| 6 | `forbidden` sans fuite d'existence | exemple partagé (`denied_role`), `lookup_tools_spec` (journal) |
| 7 | Les `ref` s'ouvrent | `refs_spec`, exemple partagé |
| 8 | Bon outil choisi à 90 % | **non fait** : jeu d'évaluation d'A12 |

## Écarts et reste à faire
- **Rapports qui agrègent en Ruby** : `AgedBalanceQuery`, `UnletteredLinesQuery` et la liste de `GeneralLedgerQuery` chargent leurs lignes en Ruby (c'est ce que font déjà les écrans). Les outils les appellent tels quels, sans recalculer. `get_ledger` refuse un compte de plus de 5000 lignes dans la période, avec la façon d'affiner ; les totaux du grand livre sont calculés en SQL (`GeneralLedgerQuery#totals`, ajouté).
- **Filtres que `Reports::Filters` déclare sans les appliquer** (brouillons, journaux, tiers du solde de vérification) : non exposés par les outils.
- **Deux ajouts aux rapports**, sans effet sur les écrans : `GeneralLedgerQuery#line_count` et `#totals`, `UnletteredLinesQuery::Row#journal_entry_id`.
- **`get_budget_vs_actual`** : pas d'outil (D11). **`calculate`, `search_knowledge`, `list_vat_codes`, `get_finding_context`** : P1.
- **Délai de 10 secondes** : `Timeout` interrompt le fil Ruby, pas une requête déjà partie (commentaire `ponytail:` dans le registre).
- **Étapes visibles** : les libellés génériques (« Looking up … ») ne donnent pas encore la durée ni les arguments ; « Voir comment j'ai obtenu ce chiffre » est pour A05.
