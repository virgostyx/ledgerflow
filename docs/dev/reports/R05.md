# R05 — Écritures non lettrées

Statut : v1 livrée (liste ligne par ligne + groupes équilibrés non lettrés). Propositions de lettrage automatiques non construites.

## Filtres
`kind` (customer/supplier/both, défaut both) · `as_of` (rétroactif, même reconstruction que R04) · `min_age_days`.

## Colonnes
Compte · Date · Journal · Référence · Échéance · Débit · Crédit · Résiduel · Ancienneté · Code de lettrage — groupé par tiers, sous-total affiché.

## Règles de calcul
`Accounting::UnletteredLinesQuery` réutilise `Accounting::OpenLineSql` (le même module que R04) — le sous-total par tiers égale **toujours** le total du même tiers dans R04, par construction (testé explicitement : `matches AgedBalanceQuery's total per partner`).

`#balanced_unlettered_groups` : regroupe les lignes ouvertes par (tiers, compte), retient les groupes de 2+ lignes dont la somme des résiduels est nulle — candidates à un lettrage immédiat.

## Drill-down
Accessible depuis R04 (clic sur "Total" du pied de tableau).

## Critères d'acceptation (§7) — état
4. Sous-total tiers R05 = total tiers R04 — ✅ garanti par construction (module partagé), testé.
5. Groupe équilibré non lettré créé dans le jeu de test apparaît — ✅ testé.

## Écarts / reporté
- **Propositions de lettrage** (paires de lignes à montants opposés égaux, ou même communication structurée) : non construites — nécessite un algorithme de matching dédié, hors du périmètre v1. Le lien vers la fonction de lettrage existante (`Accounting::LetterLines`/écran `letterings#new`) n'est pas encore câblé depuis cette page.
- Pas de recherche texte, pas de filtre montant, pas de filtre "état de lettrage" (tous/lettrés/partiels/non lettrés) — la page ne montre que les lignes ouvertes, jamais les lignes déjà closes.
- Pas d'export CSV/XLSX/PDF pour cette page.
- Icône Pièce : absente (même limitation que R02 — aucune fonctionnalité de pièce jointe dans ce dépôt).
