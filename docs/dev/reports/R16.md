# R16 — Fixed assets and depreciation (v1)

Most of R16 already existed (`Accounting::FixedAsset`, `PostDepreciation`, `DisposeFixedAsset`, register and forward plan on the fixed-assets page, straight-line pro rata by month, plan summing to the depreciable base to the cent). Built here:

- `Accounting::FixedAssetMovementsQuery` + page `reports/fixed_asset_movements`: per category (asset-account family 21–24) A. cost (start / acquisitions / disposals / end), B. depreciation (start / booked / reversed on disposal / end), C. net book value = A − B, all aggregated in SQL from the register; the year's disposals with cost, accumulated depreciation, net book value, price and gain or loss.
- **I10** checks (`spec/invariants/i10_*`): register cost = ledger balance of accounts 21–24 (land 220100 and accumulated accounts excluded), register accumulated depreciation = ledger accumulated accounts, year charge = ledger 630. The reference ledger now carries a depreciated asset (6 000 € contributed in kind, booked against 100000 so bank / aged balance / VAT are untouched); I1–I10 all hold. An unregistered posting shows as a difference (tested).
- Migration `20260929000400`: `accounting_fixed_assets.disposal_price` (optional field on the disposal form). It only feeds the gain/loss figure — never booked; the sale stays invoiced on 760100.

## Deviations and deferrals
- Depreciation generation posts **validated** entries (existing flow), not drafts as the spec asks (criterion 5). Changing it would alter closing (`CloseFiscalYear` checks pending depreciation) — left for your call.
- Not built: degressive method and its law-limit table, pro rata by days (only by month), transfers column, per-asset history view / drill-down to entries, XLSX/CSV export, a "current fiscal year" selector beyond `fiscal_year_id`.
- Gain/loss = price − net book value at disposal, computed from `disposal_price` (a spec criterion "partial-year disposal gives the right gain/loss" is tested with a 30 June disposal: −1 200 €).
