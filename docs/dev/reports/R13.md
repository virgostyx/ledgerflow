# R13 — Dashboard (v1)

- `Accounting::DashboardKpis`: 10 cards (cash, revenue YTD, gross margin %, monthly fixed costs, result YTD, DSO, DPO, working capital, overdue receivables, cash coverage) shown under "Key indicators" on the accounting dashboard. Each carries its formula (tooltip), a link to the source report and a status colour. Figures come from `TrialBalanceQuery` / `AgedBalanceQuery`; a failing indicator shows an error message on its own card only. Ratios are empty (—) when the denominator is zero.
- Migration `20260929000100`: `accounting_accounts.fixed_cost` (checkbox on the account edit form) feeds "monthly fixed costs".
- Interpretations (prudent, to validate): gross margin's "cost of sales" = class 60; DSO/DPO use debits of 40 / credits of 44 in the period as TTC sales/purchases (credit notes are not netted); working capital = 3 + 40 + 41 − 44.
- Deferred: `kpi_snapshots` + `ledger_version` invalidation, 12-month sparklines (spec §17 charts, ECharts not installed), N-1 / budget comparison, per-entity configurable thresholds (v1 uses fixed defaults: cash/result < 0 red; coverage < 1 month red, < 3 orange; DSO > 60 orange, > 90 red), the I1–I11 invariant status cards.
